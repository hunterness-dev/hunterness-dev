## Featured Projects

### 🏠 House Price Predictor — From Scratch
> Linear Regression implemented with NumPy and gradient descent. No sklearn for the model core.

![R²](https://img.shields.io/badge/R%C2%B2-0.957-success?style=flat-square)
![NumPy](https://img.shields.io/badge/NumPy-013243?style=flat-square&logo=numpy&logoColor=white)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=flat-square&logo=streamlit&logoColor=white)

- Custom gradient descent with configurable learning rate and epochs
- L2 regularization (Ridge) and polynomial feature support
- Matches scikit-learn performance (R² = 0.957) without using it for the model
- Streamlit web UI + CLI interface with model save/load

[→ View Repository](https://github.com/hunterness-dev/house-price-predictor-from-scratch)

### 📊 ML Algorithm Progression — Benchmarked
> A structured series of 10 ML projects, each building on the last. Scripts, datasets, visualizations, and documented results all included.

| Algorithm | Dataset | Best Metric | Notes |
|---|---|---|---|
| Linear Regression | Diabetes | R² = 0.96 | BMI, BP, age explain 96% variance |
| Polynomial + CV | Diabetes (BMI) | RMSE = 62.46 | Degree 1 optimal — higher degrees overfit |
| Ridge vs Lasso | Polynomial (deg 15) | R² = 0.959 | Lasso reduced 15 → 5 features |
| KNN | Spam emails | Acc = 100% | Clean dataset, perfect separation |
| Decision Tree | Spam emails | Acc = 96.0% | Depth = 3, word count = 70% importance |
| Random Forest | Spam emails | AUC = 0.80 | +4% over single Decision Tree |
| XGBoost (tuned) | Spam emails | Acc = 75.5% | GridSearchCV, +2.5% over RF |
| Neural Network | Spam emails | AUC = 0.833 | 3 layers, BatchNorm + Dropout |
